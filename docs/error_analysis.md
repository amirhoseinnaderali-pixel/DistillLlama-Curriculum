# Error Analysis

Use a consistent taxonomy across Base, SFT, KD, Curriculum, and CGKD-CR outputs.

Primary categories:
- algorithmic misunderstanding
- reasoning failure
- hallucinated API or library usage
- syntax error
- compilation error
- runtime error
- wrong algorithm
- off-by-one
- incomplete solution
- timeout
- memory failure
- training-format overfitting

Category assignments should be based on observed failure evidence.
